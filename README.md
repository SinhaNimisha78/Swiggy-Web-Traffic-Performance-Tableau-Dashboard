# Swiggy Web Traffic Performance Dashboard

## Project Overview

This project presents an interactive Tableau dashboard to analyze Swiggy web traffic performance and identify key business trends and insights.

* Analyze Swiggy web traffic performance.
* Track important business KPIs.
* Identify trends and patterns.
* Present insights through interactive visualizations.
* Support data-driven business decision-making.
